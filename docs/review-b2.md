# Отдельное ревью B2

**Дата:** 2026-10-07  
**Первоначальный вердикт:** нужна доработка.

## Находка R1

**Файл:** `compose.yaml`  
**Контракт:** app и postgres используют один набор переопределяемых реквизитов.

У `postgres` переменные `POSTGRES_DB`, `POSTGRES_USER` и `POSTGRES_PASSWORD` допускали замену, но `DATABASE_URL` app был захардкожен на `shop`.

**Исправление:** `DATABASE_URL` теперь строится из тех же Compose-переменных.

**Проверка:** `docker compose config` с `review_db`, `review_user`, `review_password` показывает одинаковые значения у обоих сервисов.

**Повторная проверка:** R1 подтверждена независимым ревьюером.  
**Ограничение:** запуск app-контейнера остаётся непроверенным из-за запрета среды на Docker buildx-кэш.  
**Итоговый вердикт:** R1 принято; B2 ожидает реального запуска app-контейнера.
