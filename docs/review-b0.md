## Находка R1

**Файл:** `Makefile`  
**Контракт:** B0-T01 — установка по lock и `make check` должны воспроизводиться в чистом окружении.

**Воспроизведение после исправления:**

```sh
env -i PATH=/usr/bin:/bin:/usr/sbin:/sbin /usr/bin/make check
```
